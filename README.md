# Odin Recipes

Following The Odin Project, this is a HTML only website listing recipes.

## Reflection
From this project I confirmed I learned the following:

- Using lists, ordered & unordered
- Basic website navigation, going back and forth between pages
- Provide images, with consistent sizing across all webpages & annotations describing the images for accessbility
- Correctly use headings, and know when to switch to a different heading for content

### Next Steps

- Learn CSS & make the website prettier to look at.
